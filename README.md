# TerraBuddy Mobile UI Clone

This project recreates the dashboard design shown in your reference video as a React Native mobile app.

## Implemented Screens
- Home
- Plant Disease Detection
- Pest Outbreak Alerts
- Equipment Sharing
- Government Schemes
- Voice Assistant

All screens are accessible through a custom bottom tab bar and include matching cards, chips, sections, and CTA layouts from the design.

## Run
1. Install Node.js (LTS) and npm.
2. Install Expo CLI:
   `npm install -g expo-cli`
3. Install dependencies:
   `npm install`
4. Start app:
   `npx expo start`

Then open Android/iOS emulator or scan the QR with Expo Go.
